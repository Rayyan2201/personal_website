# Rayyan Muhammad Arraffi — Personal Website

Website personal/CV online statis berbasis HTML, CSS, dan JavaScript. Tidak perlu install Node.js, database, atau package tambahan.

## Cara menjalankan
1. Ekstrak file `rayyan-portfolio.zip`.
2. Buka folder `rayyan-portfolio`.
3. Klik dua kali `index.html` untuk membukanya di Chrome, Edge, Firefox, atau browser modern lainnya.

## Fitur
- Desain portfolio modern dengan latar bersih, aksen merah, detail grid, dan efek animasi yang halus.
- Menggunakan nama lengkap **Rayyan Muhammad Arraffi** pada identitas website.
- Menggunakan foto profil terbaru yang diberikan.
- Responsif di komputer, tablet, dan ponsel.
- Mode tema System / Light / Dark: secara default mengikuti preferensi warna browser/perangkat dan menyimpan pilihan manual di browser.
- Menu navigasi mobile dan efek reveal saat menggulir.
- Tombol **Cetak / Simpan CV** membuka dokumen sumber `assets/CV.pdf` di tab baru. Gunakan kontrol PDF browser untuk mencetak atau mengunduhnya.
- Tautan email dan telepon langsung.

## Publikasi ke internet
Unggah seluruh isi folder ini ke layanan hosting statis seperti GitHub Pages, Netlify, atau hosting milik sendiri. Unggah seluruh folder/isi folder, bukan hanya `index.html`, agar CSS, JavaScript, foto, dan favicon ikut termuat.

## Pembaruan visual dan interaksi

Versi ini menambahkan progress bar saat scroll, navigasi aktif berdasarkan bagian halaman, animasi reveal bertahap, efek hover pada kartu, tilt 3D foto profil untuk perangkat desktop, dan ripple pada tombol utama. Efek interaktif dibuat tanpa library tambahan dan mengikuti preferensi `prefers-reduced-motion`.

### Menjalankan website

Buka `index.html` langsung di browser modern. Website tidak memerlukan proses build atau instalasi dependency. Untuk memastikan semua file aset tetap ditemukan, pertahankan struktur folder `assets/`, `index.html`, `styles.css`, dan `script.js`.
